Verification & Validation Research Framework

This cockpit provides a reusable deterministic DP resilience simulation framework for research, verification and validation activities.

The framework is designed so that external research partners may provide their own:
• scenarios
• operating conditions
• resilience metrics
• evaluation criteria
• verification conditions
• validation requirements

These requirements can subsequently be mapped into the existing Sextant Protocol™ simulation architecture without changing the underlying layered decision-support framework.
